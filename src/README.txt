Instructions for using the Python version of the PFAS-LEACH-Screening analytical solver 

1. The PFAS-LEACH-Screening solver includes two source code files "analytical_soln.py" and "utils.py".
2. "main_field_example.py" provides an example for applying the PFAS-LEACH-Screening solver to compute PFAS leaching in the vadose zone. Users can create their own examples to accomodate different input and output requirements (e.g., the need to run a series of cases). 
3. Detailed comments and definitions of the variables are provided in the source code files. It is recommended that users go through them before modifying the input parameters in the example.
